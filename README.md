# EnerflexCBD — лендинг (тестовое задание)

## Демо

**https://palina-mrk.infinityfreeapp.com/**

## Описание

Одностраничный лендинг с адаптивной вёрсткой, попапом заказа, слайдером отзывов (Swiper), мобильным меню и отправкой формы на бэкенд через `api.php` (прокси к API sendmelead).

## Запуск локально

Для проверки из исходников (без хостинга):

**Требования:** PHP 7.4+, расширение openssl, браузер.

```bash
cd /path/to/project
php -S localhost:8080
```

Открыть: **http://localhost:8080/**

> Страницу нужно открывать по HTTP, не через `file://`.

Остановка сервера: **Ctrl+C**.

## Что проверить

| Функция | Как проверить |
|---------|----------------|
| Вёрстка | Ресайз окна, мобильное меню (бургер) |
| Попап заказа | Кнопки **Order** → форма в модальном окне |
| Форма | Заполнить имя и телефон → кнопка активна → отправка |
| Отзывы | Листание слайдера, пагинация |
| FAQ / efficacy | Раскрытие блоков по клику |
| Zoom диаграммы | Наведение на круг (ширина экрана ≥ 1220px) |

При тесте формы: в `input.js` ограничение — 2 заказа с одного браузера и блок повторного номера (сброс через Local Storage или инкогнито).

## Состав проекта

| Файл | Назначение |
