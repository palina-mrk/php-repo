## Перед сдачей ТЗ — проверить вручную

### Форма заказа
- [ ] Попап открывается только по клику **Order** (не сам по себе)
- [ ] Заполнение имени и телефона → кнопка **Order** активна
- [ ] Успешная отправка → попап закрывается, сообщение об успехе, остаёмся на странице
- [ ] Ошибка API → сообщение об ошибке, форма остаётся открытой
- [ ] `api.php` доступен на хостинге с PHP и исходящим HTTPS до sendmelead.com

### Навигация и вёрстка
- [ ] Все изображения и `style.min.css` загружаются (нет 404 в Network)
- [ ] Слайдер отзывов листается
- [ ] FAQ / блок efficacy раскрываются по клику
- [ ] Меню `#order` скроллит к форме (или открывает попап — по задумке)

### Локальная разработка
- [ ] Запуск: `php -S localhost:8080` в папке проекта
- [ ] Открывать `http://localhost:8080/index.html`, не `file://`
- [ ] После тестов заказов: при необходимости очистить `localStorage` и обновить страницу (лимит 2 заказа / повтор номера)

### Деплой на сервер

- [ ] Проверить токен/offerId в `api.php` (sendmelead)

### Опционально (не блокирует сдачу)

## Известные особенности шаблона (не баг)

- Попап формы клонируется в `.ever-popup` скриптом `main.js`
- Лимит заказов и проверка повторного номера — в `localStorage` (`input.js`)
- Классы `fadeIn` на блоках — для анимации при скролле (`main.js`)
